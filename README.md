| หน้า | ไฟล์ | ใครใช้ |

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ประมาณ 20 นาที)

### 1. สร้างโปรเจกต์ Firebase
1. เข้า <https://console.firebase.google.com> → **Add project** (ไม่ต้องเปิด Google Analytics) ใช้แผนฟรี **Spark** ได้
2. เมนู **Build → Firestore Database → Create database** → เลือก **Production mode** → Location: `asia-southeast1 (Singapore)`
3. เมนู **Build → Authentication → Get started → Sign-in method** → เปิด **Email/Password**
4. แท็บ **Users → Add user** → สร้างบัญชีผู้ดูแล (admin) 3–4 คน เช่น `admin1.teng@gmail.com` + รหัสผ่าน
5. แท็บ **Settings → User actions** → **คงเครื่องหมาย** *Enable create (sign-up)* ไว้ (หน้าผู้ดูแลใช้สร้างบัญชีครู · คนที่สมัครเองจะไม่มีสิทธิ์ใด ๆ เพราะกฎ Firestore ตรวจสิทธิ์จากรายชื่อผู้ดูแลและบัญชีครูที่ผู้ดูแลสร้างเท่านั้น)
6. ไอคอนเฟือง ⚙ **Project settings → General → Your apps → `</>` (Web)** → ตั้งชื่อ → **Register app** → คัดลอกค่า `firebaseConfig`

### 2. แก้ไขไฟล์ตั้งค่า (2 ไฟล์)
**`assets/js/config.js`**
- วางค่า `firebaseConfig` ที่คัดลอกมาลงใน `firebase: { ... }`
- `adminEmails` → อีเมลผู้ดูแล 3–4 คนจากข้อ 1.4
- `keySalt` → เปลี่ยนเป็นข้อความอะไรก็ได้ของสถานศึกษา (ตั้งครั้งเดียว ห้ามเปลี่ยนหลังนำเข้าข้อมูล)

**`firestore.rules`**
- แก้อีเมลในบรรทัด `request.auth.token.email in ['admin@example.com']` ให้ตรงกับอีเมลผู้ดูแล (หลายคนคั่นด้วยจุลภาค)
- คัดลอกทั้งไฟล์ไปวางที่ Firebase Console → **Firestore Database → Rules** → **Publish**

### 3. ขึ้นเว็บด้วย GitHub Pages
1. สร้าง repository ใหม่ใน GitHub (Public) เช่น `online-class`
2. **Add file → Upload files** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวม `.nojekyll`) → Commit
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://ชื่อผู้ใช้.github.io/online-class/`
5. กลับไป Firebase → **Authentication → Settings → Authorized domains → Add domain** → ใส่ `ชื่อผู้ใช้.github.io`

> ⚠️ **ห้ามอัปโหลดไฟล์ข้อมูล ITW51 (.DBF) ขึ้น GitHub** — repository เป็นสาธารณะ ไฟล์ในโปรเจกต์นี้ไม่มีข้อมูลนักศึกษา
> ค่า `apiKey` ของ Firebase เปิดเผยได้ตามปกติ ความปลอดภัยอยู่ที่ `firestore.rules`

**สร้างบัญชีครู** (admin → ครูผู้สอน)
- กด **นำเข้าจากไฟล์ Excel** → เลือกไฟล์รายชื่อบุคลากร (ต้องมีคอลัมน์ คำนำหน้า · ชื่อ · สกุล · เบอร์โทร · E-mail)
  ระบบอ่านเฉพาะคอลัมน์เหล่านี้ในเบราว์เซอร์ ไม่อัปโหลดไฟล์ · ข้ามชีตอื่น (เช่น เลขบัตร ที่อยู่ เงินเดือน)
- **กลุ่มที่ดูแลกำหนดอัตโนมัติ** โดยจับคู่ชื่อครูกับครูที่ปรึกษาใน ITW51 (GROUP.DBF) รวมชื่อที่สะกดต่างกันเล็กน้อย (ระบบแจ้งให้เห็นในตาราง) — ครูที่จับคู่ไม่ได้ ให้กด "แก้ไข" เลือกกลุ่มเอง
- ติ๊ก **ดูทุกกลุ่ม** ให้ผู้บริหาร (เช่น ผอ.) ได้ตั้งแต่ตอนนำเข้า
- บัญชีที่ไม่อยู่ในไฟล์ใหม่ เลือกปิดใช้งานได้ (ไม่ติ๊กไว้ให้ เพื่อไม่ปิดบัญชีที่เพิ่มด้วยมือ)
- **แก้ไฟล์แล้วนำเข้าซ้ำได้**: ระบบจับคู่บัญชีเดิมด้วย E-mail → แก้ชื่อที่สะกดผิด/เบอร์โทร/กลุ่มให้ ไม่สร้างบัญชีซ้ำ
  (ถ้าเบอร์โทรเปลี่ยน รหัสผ่านเดิมยังเป็นเบอร์เก่า ระบบจึงส่งลิงก์ตั้งรหัสผ่านใหม่ไปที่อีเมลครูให้อัตโนมัติ)
- ครูที่ไม่มีกลุ่ม: กด "แก้ไข" เลือกกลุ่มเอง · **ผู้บริหาร (เช่น ผอ.)**: ติ๊ก "ดูนักศึกษาและคะแนนได้ทุกกลุ่ม" — ดูได้ทั้งหมดแต่ไม่มีสิทธิ์ดาวน์โหลด/จัดการระบบ
  (ถ้าต้องการให้มีสิทธิ์ admin ครบ ให้ใส่อีเมลในรายชื่อผู้ดูแลแทน)
- เพิ่มทีละคนได้ที่ **+ เพิ่มครู**
- อีเมลที่อยู่ในรายชื่อผู้ดูแลระบบจะไม่ถูกสร้างเป็นบัญชีครู (คนนั้นเข้าระบบแท็บผู้ดูแลแทน)

**ครูเข้าระบบ** ที่ `admin.html` แท็บ "ครูผู้สอน"
- ชื่อผู้ใช้ = **ชื่อ-สกุล** (ไม่ต้องพิมพ์คำนำหน้า) · รหัสผ่าน = **เบอร์โทร** (พิมพ์มีขีดได้)
- **เปลี่ยนรหัสผ่านเองได้ 1 ครั้ง** (ปุ่มด้านบนจะหายไปหลังเปลี่ยน)
- **ลืมรหัสผ่าน**: พิมพ์ชื่อ-สกุล แล้วกด **"ลืมรหัสผ่าน?"** ใต้ช่องรหัสผ่าน → ระบบส่งลิงก์ตั้งรหัสผ่านใหม่ไปที่ **E-mail ในไฟล์รายชื่อ**
  (admin กด "ส่งลิงก์รีเซ็ต" ให้ครูได้เช่นกัน)
- อีเมลรีเซ็ตส่งโดย Firebase — แก้ข้อความอีเมลเป็นภาษาไทยได้ที่ Firebase Console → Authentication → Templates → Password reset
- **ปิดใช้งาน** บัญชีครูที่ย้าย/ลาออก ได้ทันที

**กลุ่มเรียน / ครูประจำกลุ่ม** (admin)
- แสดงทุกกลุ่มในภาคเรียน จำนวนนักศึกษา ครูที่ปรึกษาใน ITW51 และครูประจำกลุ่มในระบบนี้
- กลุ่มที่ยังไม่มีครู (เช่น ครูเกษียณ รอครูใหม่) แสดง **"รอครู"** — admin และผู้บริหารยังเห็นนักศึกษากลุ่มนี้ได้
- **เปลี่ยนครูประจำกลุ่ม**: เลือกชื่อครูคนใหม่ในช่องของกลุ่มนั้น → ย้ายจากครูคนเดิมให้ทันที (นักศึกษา บทเรียน คะแนน ไม่เปลี่ยน)
- ครูใหม่มาแทน: เพิ่มบัญชีครู (Excel หรือ + เพิ่มครู) แล้วเลือกให้กลุ่มที่หน้านี้

**กลุ่มที่ไม่นำเข้า (เช่น เรือนจำ)** — ตอนนำเข้า ITW51 มีรายการกลุ่มให้ติ๊ก "ไม่นำเข้า"
ระบบติ๊กกลุ่มที่ชื่อ/สถานที่พบกลุ่มมีคำว่า "เรือนจำ" ให้อัตโนมัติ และจำค่าไว้ใช้ครั้งต่อไป · นักศึกษากลุ่มนี้ไม่มีบัญชีออนไลน์
และการส่งคะแนนเข้า ITW51 จะไม่แตะคะแนนของกลุ่มนี้

## การใช้งานแต่ละภาคเรียน

ใช้ **Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์เครื่องที่ติดตั้ง ITW51**

### ① เพิ่มภาคเรียน / นำเข้าข้อมูล ITW51 (`admin.html` → ภาคเรียน / นำเข้า ITW51)
- กด **เลือกโฟลเดอร์** → เลือกโฟลเดอร์รหัสสถานศึกษา เช่น `...\ITW51\DATA\1257040000` (ที่มีโฟลเดอร์ย่อย 1, 2, 3)
- เลือกภาคเรียน (เช่น 69/2) → **ตรวจข้อมูล** → **นำเข้า**
- นำเข้า **ทีละภาคเรียน** — แต่ละภาคที่นำเข้าจะเป็น **เมนูภาคเรียน** ให้นักศึกษาเลือกหลังเข้าระบบ (เช่น ภาคเรียนที่ 1/2569, ภาคเรียนที่ 2/2569) นักศึกษาเห็นเฉพาะภาคและรายวิชาที่ตนลงทะเบียน
- ติ๊ก **ตั้งเป็นภาคเรียนปัจจุบัน** เพื่อให้นักศึกษาเห็นภาคนั้นเป็นค่าเริ่มต้น
- นำเข้าภาคเดิมซ้ำได้เมื่อมีการเพิ่ม/ถอนรายวิชา (ภาคอื่น บทเรียน และคะแนนเดิมไม่หาย)
- ตาราง **ภาคเรียนในระบบ** ใช้ตั้งภาคปัจจุบัน หรือลบภาคเรียนออกจากเมนูนักศึกษา
- ช่องเลือกภาคเรียนที่มุมซ้ายของหน้าผู้ดูแล ใช้สลับภาคที่กำลังจัดการ (บทเรียน ผลคะแนน ส่งคะแนนเข้า ITW51)
- ไฟล์ถูกอ่านในเบราว์เซอร์ ไม่ถูกอัปโหลด · ระบบเก็บเฉพาะรหัส ชื่อ กลุ่ม รายวิชาที่ลงทะเบียน
  เลขบัตรประชาชนถูกแปลงเป็นรหัสลับทางเดียว (SHA-256) ไม่ถูกเก็บในระบบ

### ①-ข เตรียมภาคเรียนล่วงหน้า (ก่อนเปิดเทอม)
ใช้เมื่อรู้แล้วว่าภาคหน้าจะเปิดสอนวิชาอะไร แต่นักศึกษายังไม่ได้ลงทะเบียนใน ITW51
1. ภาคเรียน / นำเข้า ITW51 → **+ เตรียมภาคเรียนล่วงหน้า** → เลือก ภาคเรียนที่ 2 ปี 2569
2. รายวิชา / บทเรียน → **+ เพิ่มรายวิชา** ได้ 3 วิธี: **พิมพ์เอง** · **เลือกจากรายวิชาใน ITW51** (อ่านจาก SUBJECT.DBF) · **คัดลอกจากภาคเรียนอื่น**
3. สร้างบทเรียนของแต่ละวิชารอไว้ (นักศึกษายังไม่เห็น)
4. เปิดเทอม นักศึกษาลงทะเบียนแล้ว → **นำเข้า ITW51** ภาคนั้น → ระบบจับคู่ตาม **รหัสวิชา** นักศึกษาแต่ละคนเห็นเฉพาะวิชาที่ตนลงทะเบียน พร้อมบทเรียนที่เตรียมไว้
- รหัสวิชาต้องตรงกับใน ITW51 · วิชาที่เตรียมไว้แต่ไม่มีใครลงทะเบียนจะแสดง "รอลงทะเบียน" และลบได้

### ② สร้างบทเรียน (รายวิชา / บทเรียน → คลิกวิชา)
1. **วิดีโอ + คำถาม** — วางลิงก์ YouTube (แนะนำตั้งเป็น *ไม่เป็นสาธารณะ / Unlisted*) → โหลดวิดีโอ → เล่นไปยังจุดที่ต้องการ → **+ เพิ่มคำถาม ณ เวลานี้** → พิมพ์คำถาม ตัวเลือก คลิกวงกลมหน้าคำตอบที่ถูก

### ④ ผลคะแนน
- ดูรายวิชา/รายคน · ดาวน์โหลด CSV
- **คำนวณและประกาศคะแนน** → ยืนยันคะแนนทางการ (ใช้เมื่อแก้เฉลยภายหลัง เพื่อคำนวณใหม่จากคำตอบที่เก็บไว้)
- **ล้างผล…** ให้นักศึกษารายคนสอบใหม่/ดูวิดีโอใหม่

### ⑤ ส่งคะแนนเข้า ITW51 (ช่องคะแนนกลางภาค)
1. **ปิดโปรแกรม ITW51** และสำรองโฟลเดอร์ข้อมูลก่อน
2. เลือกโฟลเดอร์ ITW51 (ปุ่มสีเขียว = บันทึกกลับได้โดยตรง ใช้ได้ใน Chrome/Edge)
3. เลือก **ช่องคะแนนกลางภาคย่อย** ที่จะใส่ (ระบบแสดงว่าช่องไหนว่าง/ใช้อยู่ · ข้อมูลภาค 69/1 ใช้ช่อง 1,2,4,5,6,8 อยู่ ช่อง 3,7,9 ว่าง)
4. **คำนวณและแสดงตัวอย่าง** → ตรวจรายการ (ระบบเตือนถ้ากลางภาครวมเกินคะแนนเต็มใน `RULE.DBF` ปกติ 60)
5. **บันทึกลงโฟลเดอร์ ITW51 โดยตรง** (ระบบสำรอง `GRADE_BAK_วันเวลา.DBF` ให้อัตโนมัติ)
   หรือ **ดาวน์โหลด** แล้วเปลี่ยนชื่อเป็น `GRADE.DBF` วางแทนไฟล์เดิมในโฟลเดอร์ระดับนั้น
6. เปิด ITW51 → **ประมวลผลการเรียน** ใหม่ (ระบบนี้ปรับ MIDTERM และ TOTAL แต่ไม่คำนวณเกรด)

สิ่งที่ระบบแก้ใน `GRADE.DBF`: เฉพาะระเบียนของภาคเรียนที่เลือก → ช่อง `MIDTERMx` ที่เลือก, `MIDTERM` (= ผลรวมช่องย่อย 1–9), `TOTAL` (= MIDTERM + FINAL) และวันที่แก้ไขในหัวไฟล์ — ขนาดไฟล์และข้อมูลอื่นเหมือนเดิมทุกไบต์

## โหมดทดลอง
ถ้ายังไม่ใส่ค่า Firebase ใน `config.js` ระบบจะทำงานใน *โหมดทดลอง* — เก็บข้อมูลในเบราว์เซอร์เครื่องนั้น ใช้ทดลองนำเข้า ITW51 สร้างบทเรียน และทดสอบหน้านักศึกษาได้ทันที
(เปิดผ่านเว็บเซิร์ฟเวอร์ เช่น GitHub Pages หรือ `python -m http.server` — เปิดไฟล์ตรง ๆ แบบดับเบิลคลิกจะไม่ทำงาน)

## ขีดจำกัดแผนฟรี (Spark)
